# 🐳 Cloud_Docker

Repositorio dedicado a aprender y trabajar con **Docker** en entornos cloud.

## 📚 Contenido

Este repositorio contiene ejemplos, configuraciones y mejores prácticas para trabajar con Docker.

### 📖 Fundamentos de Docker

Para entender los conceptos básicos de Docker, consulta el archivo de fundamentos:

- **[Fundamentos Docker](./FUNDAMENTOS_DOCKER.md)** - Guía completa sobre conceptos clave de Docker

### 📁 Estructura del Repositorio

- `/ejemplos` - Ejemplos prácticos de Docker
- `/configuraciones` - Archivos de configuración útiles
- `Dockerfile` - Ejemplo de Dockerfile
- `docker-compose.yml` - Ejemplo de composición de servicios

## 🚀 Inicio Rápido

```bash
# Clonar el repositorio
git clone https://github.com/Eduardo123as/Cloud_Docker.git

# Navegar al directorio
cd Cloud_Docker

# Ver los fundamentos
cat FUNDAMENTOS_DOCKER.md
```
